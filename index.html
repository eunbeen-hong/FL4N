Overview

4D scenes do not need explicit 4D primitives.

4D novel view synthesis (NVS) from a monocular video asks a model to render a dynamic scene from viewpoints and timestamps it never observed. Existing feed-forward methods answer with explicit 3D Gaussians plus motion fields, and pay for it with temporal ghosting, floaters and holes wherever primitives are mispredicted.

FL4N is the first feed-forward latent 4D NVS model. Instead of reconstructing primitives, it weaves a geometrically grounded scene prior into a single latent representation across space and time. A frozen, pretrained static latent NVS backbone supplies the 3D prior; a lightweight dynamic encoder learns only a temporal residual on top of it, isolating true scene motion from camera parallax. Training needs nothing but image synthesis and binary dynamic masks on a small amount of multi-view video.

TL;DR

Freeze a static latent view synthesizer, bolt on a small ControlNet-style dynamic branch that predicts a time-conditioned residual latent, and you get a real-time 4D renderer that beats Gaussian-based feed-forward methods on every benchmark and protocol we tested.

Abstract

4D Novel View Synthesis (NVS) from monocular videos aims to render dynamic scenes across viewpoints and timestamps, requiring jointly inferring 3D structure and temporal dynamics. Existing feed-forward methods rely on explicit 3D Gaussian representations, which are prone to temporal inconsistency and severe rendering artifacts. We present FL4N, the first feed-forward latent 4D NVS model. We bypass explicit 3D primitives by weaving a geometrically grounded scene prior into a unified latent representation across space and time. To overcome dynamic training data scarcity, we learn a temporal residual on top of a frozen, pretrained static latent backbone. A lightweight dynamic encoder learns to isolate true scene motion from camera parallax. Trained purely on image synthesis with binary mask guidance, FL4N achieves state-of-the-art rendering quality for 4D NVS in real time. Our proposed latent representation successfully learns a strong 4D prior, generalizes across novel views and timestamps, and cleanly decouples view and time in the latent space.

Method

A temporal residual on a frozen static prior.

FL4N keeps the pretrained static encoder and renderer of a latent NVS model frozen, and adds a trainable dynamic encoder beside them. Everything the static model already knows about geometry and viewpoint is inherited; the new branch only has to explain what changes over time.

1

Dynamic encoder with static injection

Eight transformer layers (one third of the static encoder) take each context frame with a learnable time token. Frame-wise and global self-attention are followed by cross-attention into the frozen static features, so the branch can factor out camera-induced motion and concentrate on object motion.

2

Target-time residual adaptation

The residual latent is computed once for all context frames. For any target timestamp, the adjacent time tokens are linearly interpolated and drive an AdaLN time module ending in a zero-initialised residual gate, which starts at the static prior and progressively learns temporal corrections.

3

Frozen renderer, image-only training

Residual plus static latent is decoded by the untouched renderer at the target pose. Supervision is an L2 and perceptual loss on the image, extra perceptual and gradient losses on dynamic regions, and a BCE loss on a DPT mask head against pseudo dynamic masks. No depth, no flow, no 3D motion labels.

Why a latent model instead of yet another Gaussian pipeline?

(a) Feed-forward 4D Gaussians

Rendering is only as good as the primitives

4DGT, MoVieS, NeoVerse and C4G lift pixels into Gaussians with velocities or deformation fields under dense geometry supervision. Mispredicted attributes become ghosts, floaters and holes, and time-varying appearance must be squeezed into per-primitive parameters.

(b) Latent 4D from scratch

Would need massive multi-view dynamic data

Static latent NVS models beat Gaussians on fidelity, but extending them to dynamics without any 3D prior means learning structure and motion jointly from data that is far scarcer than static multi-view imagery.

(c) FL4N (ours)

Inherit the static prior, learn only the residual

The frozen backbone already answers where to render; the dynamic branch learns when. Asynchronous view-time sampling from synchronized multi-view video naturally disentangles the two, so a small dynamic dataset is enough.

What the ablation says

Fully fine-tuning the static model on dynamic data regresses heavily: the limited 4D data overwrites the prior it was supposed to reuse.

Freezing the renderer is crucial. Unfreezing it destabilises the latent-to-image mapping the residual branch is trying to land in.

The dynamic mask loss keeps the branch anchored on moving regions; without it, training tends to collapse over time.

Static feature injection through cross-attention gives the largest gain on dynamic regions, letting the residual branch subtract camera-induced motion it can read off the static features.

Analysis

What does the residual latent actually learn?

The static model can answer where to render but not when: with no target-time input it compresses the whole video into a single time-invariant prediction. The residual supplies the missing temporal axis, and it does so only where motion happens.

Zero-shot matching · DAVIS

Dynamic latent matches better where things move

Probing dense correspondence with the protocol of Nam et al., the dynamic latent beats the static latent on the whole frame and the gap widens on dynamic regions, where moving content breaks the multi-view consistency the static prior relies on.

Video depth probing · Kubric

Geometry is preserved, temporal cues are added

A DPT depth head trained on frozen latents is consistently more accurate on the dynamic latent than on the static one, and the advantage grows with the temporal stride between context frames, i.e. with larger object motion.
